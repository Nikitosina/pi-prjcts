    Worktrees

    Each coding worker gets its own git worktree; scouts and reviewers read PR heads from snapshots. A worktree is removed automatically once its work settled, it is clean, and its commits are pushed or its PR is merged or closed. Branches are always kept; anything with changes, unpushed commits, an open PR or running work stays.
