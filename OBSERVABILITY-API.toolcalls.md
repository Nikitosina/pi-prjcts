# Tool calls in transcripts

Coordinator messages in `show` and items returned by `thread-history` / `legacy-thread-history` include tool calls as transcript items. `show` represents these with `role: "tool"`, an empty `text` field, and the tool fields below; existing user and assistant text entries are unchanged. Existing user and assistant text items keep their fields and text-slicing behavior. Tool items have `{ id, kind: "tool", name, argsPreview, status, resultPreview, at }`; previews are capped at 500 characters. `status` is `ok` or `error` when the transcript contains the matching result, and `pending` if no result is present. Paging counts tool items as transcript items, while `textOffset` and `textLimit` still apply to each item's text only. Tool items have no text field and do not consume text-slice characters.
